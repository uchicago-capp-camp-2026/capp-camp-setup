Preparing for CAPP 30121
========================

This page is intended to be used by students who were unable to attend
CAPP Camp. It contains:

- instructions for setting up the software that you will use during CAPP 30121 and many subsequent CS courses,
- slides from CAPP Camp that cover many of the tools used in CAPP 30121, and
- links to practice labs.

If you have questions about any of these topics or you run into
problems installing software, please feel free to reach out by direct
message on the CAPP Slack Workspace to Anne Rogers (MacOS) or James
Turk (Windows).


Network setup
-------------

If you have used the eduroam wireless network on another campus, you will need to "forget" it and then rejoin (from campus) using your UChicago CNetID and password:

- `How to forget a network on macOS <https://support.apple.com/en-us/102480>`__
- `How to forget a network on Windows <https://www.solveyourtech.com/how-to-forget-a-network-on-windows-11-step-by-step-guide/>`__

Slides and Practice Labs
------------------------

**Working at the command-line:**

- `Linux slides <https://people.cs.uchicago.edu/~jturk/linux.pdf>`__
- :ref:`File System Practice Lab <filesystem-practice>`
- `A tutorial on navigating the file system <https://uchicago-cs.github.io/student-resource-guide/tutorials/linux-filesystem.html>`__

**Version Control: Git**

- `Introduction to Git Slides <https://people.cs.uchicago.edu/~jturk/git.pdf>`__
- :ref:`Git Practice Lab <day2_practice>`
- `A tutorial on working locally with Git <https://uchicago-cs.github.io/student-resource-guide/tutorials/git-local.html>`__.  The files needed for this tutorial can be found in the ``capp-camp-files/git-tutorial`` directory, which you can pick up using :ref:`these instructions <day1-materials>`.

If you wish to do the Git practice lab, please send a direct message
with your GitHub username to James Turk on the CAPP Slack Workspace.
He will create a repository for you.

**Workflow**

- `Workflow Slides <https://people.cs.uchicago.edu/~jturk/workflow.pdf>`__
- :ref:`Workflow Practice Lab <create_day3_repo>`

If you wish to do the workflow practice lab, please send a direct
message with your GitHub username AND your CNetID to James Turk on the
CAPP Slack Workspace.  He will create a repository for you and he will
add you to the CAPP Camp Gradescope site.
